# OMPYR — ORGANIZATION REGISTRY

## Purpose

The Organization Registry is the central source of truth for the OMPYR organization.

It keeps track of:

- Founder
- OMPYR OP
- Departments
- Agents
- AI Models
- Tools
- Projects
- Workflows
- Permissions
- Memory
- Security Status

## 12. Manager Responsibility

Department managers coordinate agents inside their department.

They may:

- Assign tasks
- Review results
- Monitor progress
- Report to OMPYR OP
- Request additional agents
- Request additional tools


## 13. OMPYR OP Responsibility

OMPYR OP coordinates the complete organization.

OMPYR OP may:

- Assign cross-department tasks
- Create task plans
- Coordinate managers
- Select AI models
- Request new agents
- Request new departments
- Monitor projects
- Review reports
- Request approvals


## 14. Founder Approval

Founder approval is required for major changes such as:

- Powerful new agents
- Powerful new departments
- Sensitive integrations
- Major permission increases
- Production deployment
- Financial actions
- Critical security changes
